Laboratory 1: Through this activity, I learned how to create and improve a social media newsfeed interface in Flutter using custom widgets and responsive design techniques. During the process, I encountered some difficulties with displaying local image assets, organizing layouts, and handling Git branches when uploading changes to GitHub. I learned that proper file path configuration in `pubspec.yaml` is important for loading assets correctly, while keeping repository branches synchronized helps avoid version control issues. To address these challenges, I used `flutter_screenutil` for responsive layouts and improved the `NewsFeedCard` widget to handle different types of media, user profile pictures, and interactive buttons. I also used terminal commands such as `flutter pub get` and `git push` to apply dependencies and upload my updates. After making the necessary adjustments, I successfully displayed the newsfeed posts, images, and action buttons on the emulator. Overall, this activity helped me improve my understanding of Flutter UI development, widget organization, responsive design, and proper GitHub workflow.
